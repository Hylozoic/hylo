# Hylo mobile (`apps/mobile-leap`)

Expo / React Native shell for Hylo. Same store listings as the old app (`com.hylo.HyloA` / `com.hylo.hyloandroid`). Native `ios/` and `android/` are generated by `expo prebuild` and are gitignored.

## Local setup

1. Copy `.env.example` to `.env` and fill values (or copy from 1Password / a teammate).
2. From the monorepo root:

```shell
yarn install
yarn build-packages
yarn mobile-leap:dev
```

Then in another terminal:

```shell
yarn mobile-leap:ios
# or
yarn mobile-leap:android
```

`yarn mobile:dev` / `yarn mobile:ios` / `yarn mobile:android` are aliases for the same commands.

## CI

Bitrise runs `apps/mobile-leap/scripts/bitrise-make-env.sh`, `configure.sh`, then `bitrise-build.sh <ios|android>` (prebuild + signing patches + pods).
